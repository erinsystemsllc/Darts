# Client SPA (Vite + React)

This is a single‑page application generated according to the task requirements.

## Setup
```bash
cd client
npm install
```

## Development
```bash
npm run dev
```
Open http://localhost:5173 in your browser.

## Build
```bash
npm run build
```
The production files are emitted to the `dist` folder.

## Preview Production Build
```bash
npm run preview
```

## Type Checking
```bash
npm run typecheck
```
